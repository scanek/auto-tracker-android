# 🚗 Бортовой Журнал (AutoTracker) — Android App

Автономное мобильное приложение для учета расходов, обслуживания (ТО), заправок, шин и регламентов автомобиля для Android.

## ✨ Ключевые возможности

- **100% Offline (Автономность)**: Приложение полностью работает без подключения к интернету. Все данные хранятся локально на вашем смартфоне в защищенной базе IndexedDB.
- **Миграция и перенос бэкапа (.json)**:
  - Прямой импорт резервных копий из веб-версии Бортового Журнала.
  - Экспорт бэкапа со смартфона в файл `.json` в один клик.
- **Гараж и автомобили**: Неограниченное количество авто с характеристиками, пробегом, моточасами, типами привода и спецификациями масел.
- **Журнал ТО и запчастей**: Учет работ, стоимости работы и запчастей, каталожных номеров, магазинов и ссылок.
- **Умные регламенты (Reminders)**: Отслеживание сервисных интервалов по пробегу, моточасам и времени (месяцам) со встроенным пакетом регламентов.
- **Заправки и расход топлива**: Учет литров, стоимости, расчет расхода на 100 км, пропущенных заправок и графики динамики.
- **Шины, диски и датчики TPMS**: Учет сезонности, глубины протектора, привязка ID датчиков давления к колесам (FL, FR, RL, RR) и интерактивная схема ротации (перекрестная, параллельная, перед-зад).
- **Паспорт расходников**: Карточки артикулов масел, фильтров, свечей и жидкостей с удобным копированием OEM-кодов.
- **Документы и страховки**: ОСАГО, КАСКО, техосмотр, права с напоминанием об окончании срока.
- **Опциональная синхронизация с сервером**: В настройках можно привязать адрес своего веб-сервера (Self-hosted) для фоновой синхронизации.

## 📱 Установка готового APK

Готовый установочный файл находится в корне репозитория:
- **`AutoTracker-debug.apk`** (~4.3 МБ)

### Инструкция по установке:
1. Скопируйте `AutoTracker-debug.apk` на смартфон (через USB, Telegram, Google Диск или браузер).
2. Нажмите на файл в проводнике телефона и подтвердите установку.
3. При необходимости включите «Разрешить установку из неизвестных источников» для вашего проводника/браузера.

### Как перенести данные из веб-версии:
1. В веб-версии откройте **⚙️ Настройки** -> **«Экспорт всей базы (JSON)»** или **«Экспорт моего гаража (JSON)»**.
2. Отправьте скачанный `.json` файл себе на смартфон.
3. Откройте приложение на Android, перейдите в **⚙️ Настройки** -> **«Восстановление из JSON»** -> выберите файл.
4. Все автомобили, записи ТО, чеки и заправки мгновенно появятся в приложении!

## 🛠 Сборка из исходного кода

### Требования:
- **Node.js**: 18+ (рекомендуется 20+)
- **JDK**: 17 или 21 (подходит JBR из Android Studio)
- **Android SDK**: с установленной платформой `android-36` и `build-tools`

### Быстрая сборка в 1 клик (Windows):
Просто запустите скрипт:
```cmd
build-apk.bat
```

### Сборка вручную через консоль:
```bash
# 1. Установка зависимостей
npm install

# 2. Сборка веб-модулей
npm run build

# 3. Синхронизация нативного Android-проекта
npx cap sync android

# 4. Сборка APK через Gradle
cd android
./gradlew assembleDebug
```
Скомпилированный файл будет расположен в:
`android/app/build/outputs/apk/debug/app-debug.apk`
